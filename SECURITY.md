# Security

To report a potential security vulnerability in an NVIDIA product, use the
[Security Vulnerability Submission Form](https://www.nvidia.com/object/submit-security-vulnerability.html)
or email psirt@nvidia.com. Please do not report vulnerabilities through GitHub
issues or pull requests.

Include the affected product and version, reproduction steps, potential impact,
and any proof of concept. For encrypted email, use the
[NVIDIA PSIRT public PGP key](https://www.nvidia.com/en-us/security/pgp-key).

See NVIDIA's [PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/)
for the coordinated vulnerability disclosure process.
